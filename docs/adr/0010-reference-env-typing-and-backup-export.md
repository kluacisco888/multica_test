# 参照环境允许在输入框里打字预览、导出一次备份

智能识别（EURO-27）要和滴答核对：同一句话，滴答识别出什么日期、时间、重复和提醒。这只有在「添加任务」输入框里打字才看得到，ADR-0008 不允许打字。导入滴答 CSV（EURO-30）需要知道滴答备份文件的格式，这要在「设置 → 关联与导入」里点「生成备份」下载一份，ADR-0008 不允许这类点击。维护者在 EURO-2 上（2026-10-15）授权：小队可以自己在参照环境里打字测试，也可以自己导出备份，再按格式造 mock 数据测试。

## 规则

- **打字预览**：截图工具可以在添加任务、快速添加这类输入框里输入文字，用来看识别高亮和预览。不按回车，不点添加或保存按钮，截完图把输入框清空或按 Esc 关掉。只能在输入框里打字，不能在任务标题、描述、评论这类会自动保存的地方打字。
- **导出备份**：允许点「生成备份」下载备份文件，每个子任务最多一次。截图工具接收下载，把文件存到仓库外、只有本用户能读的目录（`~/reference-shots/<任务>/`）。如果这个导出请求是写请求、被写保护拦下了，只放行这一个请求，网址写死在脚本里，PR 里写明放行的是哪个网址。
- **备份文件里是小号的真实数据**：不提交进仓库，也不贴进评论。仓库里只提交按同样格式手写的 mock 示例（不含真实标题、清单名、时间），测试只用 mock 示例。子任务结束后删除下载的文件。
- 写保护照旧：除了上面写死的那一个导出请求，非 GET/HEAD/OPTIONS 请求和全部 WebSocket 连接照样拦截。ADR-0008、ADR-0009 的其他规则照常适用：操作写成脚本，PR 里附上脚本和 `blockedRequests`。

## Consequences

- 误按回车、误点添加，写请求也会被拦下，最坏的情况是截图失败，小号里的数据不会变。
- 下载的备份含小号的全部任务。万一提交进仓库就是泄露，所以审查时要确认仓库里只有 mock 示例。
