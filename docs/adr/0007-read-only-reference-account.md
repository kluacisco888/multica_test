# 用维护者的滴答小号作为只读参照，通过服务器上的 noVNC 浏览器访问

> 已被 ADR-0008 修订：截图工具可以按脚本做只读的导航点击。

“像素级复刻”需要一个真实的参照物。服务器上装一个 Chromium 和 noVNC，只监听 127.0.0.1。维护者通过 `ssh -L` 转发端口，在里面登录一个滴答小号。登录态保存在仓库之外的专用浏览器配置目录里，小队用 Playwright 加载这个配置去截图、对照。

规则：只读，只截图，不做任何新建、修改或删除；不把截图里的个人数据和登录态提交进仓库；全部验收结束后删除这个浏览器配置目录。

## Consequences

- 登录态留在服务器上，同一台机器上的其他智能体也能读到，所以只用小号。
- 小号的登录状态过期后，需要维护者重新登录一次。
