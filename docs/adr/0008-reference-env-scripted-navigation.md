# 参照环境允许脚本化的只读导航点击

有些滴答页面（例如日历的月、周、日、多日视图）光打开网址截不出来，要点一下才会显示。只靠 ADR-0007 的“只导航、只截图”工具，这些界面拿不到参照图。维护者在 EURO-19 上授权放宽规则：截图工具可以按脚本做导航类的点击，例如切换视图、打开菜单或下拉框、翻页、滚动，然后截图。写保护不变：非 GET/HEAD/OPTIONS 请求和全部 WebSocket 连接照样拦截。

## 规则

- 只做导航类的操作：点击视图切换、菜单、下拉框和翻页按钮，悬停，滚动。不在输入框里打字，不拖动，也不点会新建、修改、删除、完成、移动的按钮或菜单项。
- 操作写成脚本，交给截图工具执行，不手动驱动已登录的浏览器。PR 里附上用过的脚本和工具输出的 `blockedRequests`。
- 如果页面一定要发出被拦截的写请求才能显示，就停下来，请维护者在 noVNC 里截图，不要放开拦截。
- ADR-0007 的其他规则照常适用：只用小号；截图和登录态不进仓库；验收结束后删除配置目录。

## Consequences

- 点击可能误中会改数据的控件。好在写请求都被拦着，最坏的情况也只是截图失败，小号里的数据不会变。
