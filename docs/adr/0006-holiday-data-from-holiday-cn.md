# 节假日数据来自 NateScarlet/holiday-cn，缓存到数据库并内置兜底数据

国务院只发布节假日安排的通知原文，没有官方 API。“工作日”判断、按工作日重复的任务和日历上的节假日显示都依赖这份数据，所以选用开源项目 NateScarlet/holiday-cn 按年份发布的 JSON 文件（通过 jsDelivr 获取，不需要 key）。后端每天拉取一次当年和下一年的数据，存进数据库；镜像里内置一份数据，拉取失败时用它兜底。还没有数据的年份先按周一到周五计算，数据更新后，未完成的下一次实例会重新计算日期。

## Considered Options

- timor.tech 等在线 API：要实时调用，有频率限制，服务一停就没法判断工作日。
- 只用内置 JSON：每年都得手动更新，忘了更新就会算错。
