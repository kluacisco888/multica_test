# 提醒由服务端发送到飞书、微信和邮件，不用浏览器推送

提醒不依赖浏览器。到时间后由后端调度器投递到用户配置的通知渠道：飞书机器人 Webhook、微信 Webhook、SMTP 邮件（维护者用的是 QQ 邮箱和授权码）。这样网页关着、手机没装 PWA 也能收到提醒，以后的 Android 和 macOS 客户端也可以复用同一套渠道。渠道参数由用户在设置界面填写。授权码、Webhook 地址这类凭证要用 `.env` 里的密钥加密后再存进数据库，不能明文保存。

## Consequences

- 部署环境要能出网访问 `smtp.qq.com`、飞书和微信的 Webhook 地址。
- `.env` 里的加密密钥丢失后，已保存的凭证就无法解密，迁移服务器时必须连 `.env` 一起带走。
- 不做 Web Push，所以验收不再依赖 HTTPS。
