# 产品范围：自用、个人账户、先做 Web

本项目只供维护者自用，不商用。第一阶段做响应式 Web，桌面浏览器和移动端浏览器都要能用；以后再做 Android 和 macOS 客户端。只支持个人账户，每个用户只能看到自己的数据。共享清单、团队空间和付费订阅都不做。界面结构和交互照着滴答清单复刻，产品名、Logo 和图标自己设计，不使用官方素材和商标。

功能上不切 MVP，滴答清单的功能都要做，交付时按依赖分阶段推进。凡是依赖多人协作的功能都不做，包括“已分配给我”、@人、共享清单。日历订阅（CalDAV / Google）、邮件转任务和第三方集成也不做。界面只提供简体中文。

不开放注册。首个账户在部署时通过 `.env` 或初始化命令创建，之后由管理员在后台添加其他账户。

## Considered Options

- 共享清单 / 团队空间：因为只有自己用，不需要，而且会让权限模型复杂很多。
- 付费订阅：不商用，所以不需要。
